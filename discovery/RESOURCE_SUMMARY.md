These entries sum to approximately **20.3 accounted core-hours**. They are not
an exact complete-session CPU measurement or a proven upper bound: the twin
entry includes conservative reservations, some older entries omit startup,
and setup/inspection was not exhaustively metered. The accounting is well below
the 120-core-hour working ceiling; unused allocation does not justify another
physical matrix. Publication builds, network/privacy audits and other host
work are separate operational activity.

The new weak-bar Cartesian matrix uses 705.51 complete CPU seconds for its
26 fixed cases. Its initial cost-rejected attempt uses another 20.42 seconds
and remains rejected. These timings concern the specified nonreacting orbit
experiment, not a self-gravitating galaxy run.

The final stellar numerical stage uses 2,516.645190 complete CPU seconds,
approximately 42 minutes. Its first all-state native coarse map takes
416.9533 CPU seconds versus 1,126.3415 for the matching NumPy extended map,
about 2.70 times faster. All seven values and signed zeros agree exactly at
that comparison. This is a measured implementation gain for this operation,
not a universal speedup, a SIMD-double comparison or new physical evidence.

The campaign required finite jobs, low scheduling priority and one numerical
thread. Later launch records retain source/input hashes, metering and failures;
some early receipts lack complete process metadata, so this is not an
exhaustive host audit. No host timers were added. Four scientific workers were
the concurrency ceiling; allocation was not permission to displace other host work.

Source accounting comes from the twin `compute-review-05`, prediction ledger,
feedback ledger, echo ledger, collision/inertia ledgers and the public forecast
rerun receipt. The feedback ledger includes both root saved
candidate checks, 0.12 CPU seconds each; the first fails a numerically unstable
covariance contraction, and its stable equivalent passes without changing a
data value or tolerance. Neither is a trajectory reproduction.
